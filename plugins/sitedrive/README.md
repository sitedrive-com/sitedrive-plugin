# Sitedrive

![Sitedrive logo](assets/logo.png)

Connect your AI assistant to [Sitedrive](https://sitedrive.com) to read construction schedules,
track progress, and create or update scheduled work across projects and locations.

Sign in with your Sitedrive account when prompted. MCP access must be enabled for your user or account.
Every action follows your existing Sitedrive permissions; connecting the plugin does not grant additional
access to projects or administrative tools.

## Documentation

[Read the Sitedrive MCP documentation](https://api.app.sitedrive.com/mcp/docs) for setup instructions,
available tools, example prompts, permissions, and troubleshooting. The hosted server provides the
current tools and usage guidance.
